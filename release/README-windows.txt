RoastEngine - Windows
=====================

Play on the monitor:  double-click "Play RoastEngine.bat"
Play in VR:           double-click "Play in VR.bat"
The Creator (editor): bin\RoastEngine Creator.bat

Java is included; nothing else needs installing. Your mods, settings and logs live in
%USERPROFILE%\RoastEngine. If something goes wrong, logs\game-latest.log says why - please
attach it when you report a bug.

Playing in VR (Meta Quest 2 and other PC headsets)
--------------------------------------------------
1. Install the Meta Quest Link app (for a Quest) or SteamVR, and make sure it runs.
2. Connect the headset with the Link cable, or start Air Link.
3. Install the VR API mod in the game (Install Mod from File...) and switch it on.
4. Run "Play in VR.bat". The game appears in the headset; the window mirrors it.

Controls: left stick walks, right stick turns in steps, right trigger punches and uses things,
A jumps, the menu button pauses. Your two controllers are your two hands.

If the headset stays black, check the Link app shows the headset as connected, and that
RoastEngine is allowed to use OpenXR (in the Meta app: Settings > General > OpenXR Runtime).
